# Phase 2, Task 2.2: Per-Core Data Structures (GSBASE Local Storage)

## Objective
Implement per-core local storage using the GS segment register and GSBASE MSR.
Each CPU will have its own data structure containing:
- CPU ID / LAPIC ID
- Current task pointer
- Per-core errno
- Per-core scheduler state
- Per-core interrupt counter

## Design

### Per-Core Data Structure (kernel/src/arch/x86_64/percpu.rs)
```rust
#[repr(C)]
pub struct PerCpuData {
    pub self_ptr: *const PerCpuData,  // Offset 0: points to itself
    pub cpu_id: u32,                   // Offset 8: LAPIC ID
    pub lapic_id: u32,                 // Offset 12: LAPIC ID (duplicate for clarity)
    pub current_task: *mut TaskHandle, // Offset 16: current running task
    pub errno: u32,                    // Offset 20: thread-local errno
    pub interrupt_count: u64,          // Offset 24: count of interrupts handled
    pub in_interrupt: u8,              // Offset 32: currently in interrupt handler
    // Future fields will go here
    _padding: [u8; PERCPU_SIZE - 40],  // Pad to full size
}
```

### Initialization Sequence
1. During GDT allocation for each CPU, also allocate PerCpuData struct
2. Set self_ptr to point to itself (for GS-relative access)
3. Store PerCpuData address in GS_BASE MSR during AP init
4. Provide accessor functions using GS segment offset

### Access Pattern (After GSBASE set)
```rust
// Get current CPU's data
pub unsafe fn this_cpu() -> &'static mut PerCpuData {
    let ptr: *mut PerCpuData;
    asm!("mov {}, gs:[0]", out(reg) ptr);
    &mut *ptr
}

// Get per-core CPU ID
pub fn cpu_id() -> u32 {
    unsafe { this_cpu().cpu_id }
}

// Get current task
pub fn current_task() -> *mut TaskHandle {
    unsafe { this_cpu().current_task }
}
```

## Implementation Steps

1. Create kernel/src/arch/x86_64/percpu.rs
   - Define PerCpuData struct with proper alignment
   - Define PERCPU_SIZE constant
   - Implement accessor functions

2. Modify kernel/src/arch/x86_64/gdt.rs
   - Allocate PerCpuData during per-core GDT allocation
   - Set self_ptr in PerCpuData
   - Return PerCpuData reference for GSBASE setup

3. Modify kernel/src/arch/x86_64/smp.rs
   - During AP init, get PerCpuData from GDT allocation
   - Set GS_BASE MSR via wrmsr()
   - Store in per-core data: cpu_id, lapic_id

4. Modify kernel/src/arch/x86_64/mod.rs
   - Export percpu module
   - Initialize BSP per-core data

5. Update arch/x86_64/cpu.rs
   - Add wrmsr/rdmsr functions for MSR access
