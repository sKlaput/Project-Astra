ARCHITECTURE: v0.3 PHASE 1 COMPLETE
================================================================================

User Process Memory Layout (with protections):

  0x7FFF_FFFF_FFFF ┌─────────────────────┐
                   │ Stack (grows ↓)     │ Writable+Executable Disabled
  0x7FFF_FFF0_0000 ├─────────────────────┤
                   │ STACK RED ZONE      │ ← Guard page (prevents overflow)
  0x7FFF_FFEF_F000 ├─────────────────────┤
                   │ Heap (grows ↑)      │ Writable+Execute Disabled
  0x6000_0000      ├─────────────────────┤
                   │ HEAP GUARD PAGE     │ ← Guard page (prevents overflow)
  0x5FFF_F000      ├─────────────────────┤
                   │ Data/BSS            │ Writable+Execute Disabled
  0x5000_0000      ├─────────────────────┤
                   │ DATA GUARD PAGE     │ ← Guard page (prevents overflow)
  0x4FFF_F000      ├─────────────────────┤
                   │ Code (RX only)      │ Execute only, NOT writable
  0x4000_0000      ├─────────────────────┤
                   │ CODE GUARD PAGE     │ ← Guard page (prevents overflow)
  0x3FFF_F000      ├─────────────────────┤
                   │ NULL GUARD REGION   │ (0x0 - 0x10000)
  0x0000_0000      └─────────────────────┘

All segments validated at load time. No segment can map into guard regions.
