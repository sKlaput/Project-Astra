================================================================================
ASTRA OS - TESTING PROTOCOL FOR ALL FUTURE DEVELOPMENT
================================================================================

GOLDEN RULE: Every time I make changes, you should test using this protocol.

This ensures:
- Changes are validated before committing
- Regressions are caught immediately
- OS remains stable and functional
- High confidence in code quality

================================================================================
PROTOCOL OVERVIEW (5 Steps, 5-10 minutes)
================================================================================

After I make changes:

STEP 1: Verify Compilation (30 seconds)
  cargo check
  Should show: "Finished ... target(s) in X.XXs"

STEP 2: Build Release Binary (5 seconds)
  cargo build --release
  Should show: "Finished `release` ... in X.XXs"

STEP 3: Boot Test (10 seconds)
  qemu-system-x86_64 -drive format=raw,file=disk.img -m 2G -enable-kvm
  Watch for: Desktop appears, no panics

STEP 4: Run Functionality Tests (5 minutes)
  ping 8.8.8.8, netcheck, ps, ls /
  Click applications in GUI

STEP 5: Verify No Regressions (1-2 minutes)
  Mouse smooth, windows drag, terminal works, files persist

RESULT: All pass? Changes are GOOD!

================================================================================
WHAT EACH TEST VERIFIES
================================================================================

cargo check
  → Code syntax is correct
  → All imports are valid
  → No obvious type errors

cargo build --release
  → All code compiles
  → All modules link correctly
  → No undefined symbols

QEMU Boot
  → Kernel initializes
  → Memory system works
  → CPU/interrupts work
  → Desktop system works

Functionality Tests
  → Network stack works (ping)
  → All layers work (netcheck)
  → Process system works (ps)
  → File system works (ls)

GUI Tests
  → Desktop system responsive
  → Applications launch
  → No crashes during use

Regression Tests
  → Nothing else broke
  → Performance not degraded
  → File persistence works
